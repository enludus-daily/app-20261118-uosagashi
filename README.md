# うおさがし / Ripple Pond

App Store の名前：**うおさがし：数を読んで魚を釣るパズル** / **Ripple Pond: Logic Fishing**（ホーム画面の名前は「うおさがし」/「Ripple Pond」）

**マインスイーパーの推理で、水の下の魚を釣る。** 地雷の代わりに魚が隠れている。覗くとまわり 8 マスの魚の数が波紋で出る。魚がいると読んだマスに竿を垂らすと釣れる。外したり、魚を驚かせたりすると糸が 1 本切れる（3 本）。

- Bundle ID：`com.enludus.daily.013`（枠 013）
- 題材：監督の指示（daily-ideas #34 のコメント）「マインスイーパー × 釣り」。今日の Issue：daily-ideas #35
- iPhone（Duo の内側の大きな画面では、池を大きく・右に魚図鑑と釣った魚）。iOS 18 以降
- 名前・絵はオリジナル。アプリ名に「マインスイーパー」は使わない

## だれの・どう使うか
- マインスイーパー系の推理が好きだが、1 回のミスで全部終わるのと「運の 2 択」が嫌な人
- 1 池 3〜5 分。通勤・寝る前に今日の池を 1 つ。中断しても続きから

## 遊び
| | |
|---|---|
| 覗く（タップ） | まわり 8 マスの魚の数が、数字と波紋の輪で出る。0 のマスからはまわりが続けて開く |
| 釣る（道具を持ち替えてタップ） | 魚がいると読んだマスに竿を垂らす。外すと糸が 1 本切れる（マスは開く） |
| 浮き（長押し） | 「ここは魚」の印。浮きのマスは覗けない（うっかり驚かせない） |
| 糸 | 3 本。魚のいるマスを覗く・空のマスで釣ると 1 本切れる。尽きたら終わり |
| ぬし | まわりの数に **2 匹ぶん** で数える大物 |
| 群れ | 横に 3 匹並ぶ小魚。1 匹見つけたら、となりを読む |
| 水草・岩 | 魚がいないマス（はじめから見える） |
| 氷（氷の湖） | 覗いても数が見えない |
| 桟橋 | 池は下の真ん中の桟橋から、少し開いた状態で始まる |

**運の 2 択はない**：盤を作るたびにソルバー（数ごとの制約を全部の並びで数え、残りの魚の数も使う）で、桟橋から推理だけで最後まで解けるかを確かめ、解けない盤は作り直す（`Pond.generate`・`Solver`）。80 の池と今日の池 30 日ぶんで、テストで確かめている（`Tests/GameTests.swift`）。

### 釣り場（各 20 池）
| 釣り場 | 決まり | 魚 |
|---|---|---|
| 村の釣り堀（無料） | 小魚から始まり、6 池目からぬし、11 池目から群れ | フナ・タナゴ・モロコ（群れ）・ナマズ（ぬし）・ぬしのコイ（ぬし） |
| 山の渓流（Pro） | 岩が多く、ぬしが多い | ヤマメ・カジカ・アユ（群れ）・イワナ・ニジマス |
| 磯の潮だまり（Pro） | 広い。ぬしと群れが多い | メジナ・カサゴ・イワシ（群れ）・マダイ・スズキ |
| 氷の湖（Pro） | 氷のマスは数が見えない | ワカサギ（群れ）・ヒメマス・ウグイ・イトウ・アメマス |

ほかに **今日の池**（日付の種でだれでも同じ盤・1 日 1 回）と **気ままに**（小・中・大、何度でも新しい池）。

## 毎日開く理由
1. **今日の池**：だれが開いても同じ池。続けた日数と、この 7 日の釣った割合の棒。毎朝 7:30 の知らせ（設定でオン）
2. **魚図鑑**：20 種。釣るたびに大きさ（cm）が決まり、種ごとの最大の記録が残る。まだの魚は影だけ
3. **釣果カード**：いちばんの 1 匹と、答えの見えない池の絵（釣った・逃げた・覗いた）を画像で共有

## 世界観
**このアプリでは〔夏の朝の釣り堀〕が〔画面〕になり、〔マス〕が〔水面〕、〔数〕が〔波紋の輪〕、〔旗〕が〔赤白の浮き〕になる。**
- 主役：水面のマス（青緑・きらめきの弧）→ 覗くと水が透けて砂の底と小石が見え、数のまわりに波紋の輪（数が多いほど輪が増える）
- 脇役：木の桟橋の板（木目・節・釘・下の縁の厚み）のボタンと札、赤白の浮き、睡蓮の葉の水草、氷のひび、自作の魚の絵（種ごとの体の色・ひれ・側線・目）
- 釣り場ごとに水の色が変わる：村（青緑）・渓流（明るい水色）・磯（深い青）・氷の湖（白っぽい青）
- 前日までの 11 本（ネオンのライブハウス・水彩の空・木のテーブルの城・夜の水面・夜明けの空・工事現場・夜の地下鉄・町中華・地下の迷宮 ほか）と違う、**明るい昼の水辺**。見出しは丸ゴシックの極太（ペンキの看板）。画面はライトに固定

### 参考にしたもの（ui-reference）
- 釣りゲーム全般（釣った魚の図鑑・大きさの記録・魚拓）と、推理パズルの盤：仕組みの型だけを借りた。名前・絵は使わない
- 借りたもの：①釣れた瞬間に魚が水しぶきとともに跳ねる ②図鑑の未発見は影だけ ③結果で大きな数字（cm）を主役にする

## 手応えの表
| できごと | 動き | 振動 | 音（端末の中で作る） |
|---|---|---|---|

## デモで見せる流れ（起動引数 `-demo`、約 18 秒）
1. 桟橋（ホーム）→ 今日の池へ
2. 0 から覗いて、波紋が連鎖で広がる
3. 「釣る」に持ち替え、推理で分かった魚を次々と釣る（ぬしが跳ねる）

## 開発
- XcodeGen（`project.yml`）。ビルドとテストは GitHub Actions（daily-actions の再利用ワークフロー）
- ルールは `App/Sources/Model/`（Pond・Solver・Outing・Catalog・Progress）で画面から切り離し、`Tests/GameTests.swift` でテストする
- 画面の言葉は `tr("日本語", "English")` で書き、`python3 scripts/gen-strings.py` で `Localizable.xcstrings` を作る
- アイコンは `/usr/bin/python3 scripts/make-icon-pond.py`
